# Story 6.6: Industrial Local AI Distribution & Bundling

Status: ready-for-dev

## Story

As a Power Modder,
I want to bundle the local LLM engine and all modding dependencies into the application installer,
so that I can modulate mods entirely offline with zero configuration and maximum privacy.

## Acceptance Criteria

1. **Given** a clean Windows installation
   **When** the JPE Studio Setup is executed
   **Then** the Ollama binaries are placed in the application's local resource folder (`resources/bin`)
   **And** the internal AI service detects and initializes the server on first launch.
2. **Given** the application's first run
   **When** the setup wizard initializes
   **Then** it verifies local hardware (CPU/GPU) capabilities
   **And** it automatically extracts a "Core Modding Brain" (Qwen 0.5B, ~350MB) from compressed resources for immediate use.
3. **Given** the local AI engine is running
   **When** the user is offline
   **Then** all "Prompt-to-JPE" and "Cleanup Scan" features remain fully functional via the internal loopback bridge.
4. **Given** external modding dependencies (TS4Rebels bridge, Portable Python)
   **When** the app is built
   **Then** they are correctly bundled in `extraResources` and are executable from the Electron main process via `child_process`.

## Dev Notes

- **Ollama Configuration**: Use `--port 11435` (non-standard) for the internal instance to avoid conflicts with system-level Ollama installations.
- **Python Distro**: Use the Windows Embeddable Package (64-bit). Ensure `python311._pth` is configured to include the `scripts/` directory.
- **Hardware Optimization**: Use `systeminformation` library or simple `child_process` queries to detect GPU (NVIDIA/AMD) and set `OLLAMA_NUM_GPU` accordingly.
