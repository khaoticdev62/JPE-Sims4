You are a senior product designer, platform architect, and design systems engineer.

Your task is to design the complete UI/UX system for the **JPE Platform (JPE)** — an AI-powered modular ecosystem for knowledge processing, automation, AI agents, and enterprise workflows.

The design must support:

• AI workflows
• Knowledge processing pipelines
• Agent orchestration
• Data ingestion systems
• Automation dashboards
• Modular apps
• Enterprise scalability

All designs must be built using Figma Auto Layout, Variables, and reusable Components.

---

JPE PRODUCT OVERVIEW

JPE is an AI productivity and orchestration platform that allows users to:

• Upload and process knowledge sources
• Build AI agents
• Run automation pipelines
• Create workflows
• Monitor system intelligence
• Generate insights and reports
• Connect external tools and APIs

The platform is modular and supports extensible apps.
