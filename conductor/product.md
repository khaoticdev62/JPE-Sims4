# JPE Mod Translator 2.0 - Product Guide

## Initial Concept
The goal is to create a comprehensive design package for an application, including a Figma AI style sheet, UX design, screens, wireframes, and prompts to generate every single screen. The application will be built using React, Vite, CSS, and TypeScript. A key constraint is to ensure the design process and assets remain within the free token limits imposed by Figma.

## Product Definition
JPE Mod Translator 2.0 is a sophisticated ecosystem designed to streamline the translation and management of game mods. This project focuses on the design of **JPE Studio** (the flagship desktop interface) and **JPE Cloud Sync** (the supporting web/API infrastructure).

### Target Audience
- **Mod Authors:** Power users requiring precise control over internationalization.
- **Translators:** Community members of varying technical skill levels who need efficient editing tools.
- **General Players:** Everyday users who need an intuitive way to manage libraries and apply translations.

### Core Features & Design Focus
- **Advanced Translation Editor:** Support for XML, split-view editing, and glossary integration.
- **Mod Diagnostics & Sentinel:** Real-time conflict detection and integration with error reporting systems like "Better Exceptions."
- **Visual Aesthetic:** A "Modern Dark Mode" aesthetic with a strong influence from Apple TV's UX—prioritizing depth, smooth transitions, and high-quality typography.

### User Experience Goals
- **Speed and Efficiency:** Optimized for rapid bulk editing and fluid navigation.
- **Ease of Learning:** Intuitive enough for non-technical users to contribute immediately.
- **Immersive Focus:** A distraction-free environment tailored for long-form translation sessions.
