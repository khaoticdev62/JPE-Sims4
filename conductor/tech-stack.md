# Technology Stack

## Frontend (Desktop & Web)
- **Framework:** React
- **Build Tool:** Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Component Library:** Radix UI / Shadcn UI (Headless components for maximum customization)

## State & Data
- **Global State Management:** Zustand
- **Data Fetching & Sync:** TanStack Query (React Query)

## Design Integration
- **Design Tokens:** JSON (Exported from Figma for consistent theme management)
- **Visual Influence:** Apple TV UX (Implemented via custom Tailwind animations and transitions)

## Deployment & Hosting
- **JPE Cloud Sync:** Web API (Integrated with frontend via TanStack Query)
- **JPE Studio:** Desktop application (Built as a web-wrapped or native-compatible React app)
