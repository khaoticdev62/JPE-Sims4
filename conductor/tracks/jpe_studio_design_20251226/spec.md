# Track Spec: JPE Studio Design System & Core Screen Prompts

## Overview
This track focuses on establishing the visual foundation and the initial dashboard design for JPE Studio. The goal is to create a design system that reflects the "Modern Dark Mode" aesthetic with heavy Apple TV UX influence (depth, focus, fluid transitions) while staying within Figma's free AI token limits using an atomic prompt strategy.

## Objectives
- Define the core design tokens (colors, typography, spacing) in a JSON-compatible format.
- Create atomic-level Figma AI prompts for reusable UI components (Buttons, Inputs, Cards).
- Design the JPE Studio Home Dashboard wireframe and UX flow.
- Generate high-fidelity screen prompts for the Dashboard.

## Key Features (Dashboard)
- Project Overview: Display active mod translation projects.
- Recent Activity: Show recent changes and health status.
- Focused Navigation: Highlighted cards with subtle glow/scale effects.
- Depth & Layering: "Floating" elements over a deep dark background.

## Technical Constraints
- Must use JSON for design tokens.
- Prompts must be split into atomic parts to avoid Figma AI token limits.
- Aesthetic: Deep Dark Mode, Apple TV UX Patterns.
