## 1. Lint/Style Violations (BLOCKING)

### 1.1 Unused Variables/Imports (~80 issues)

**Pattern:** Symbols imported/declared but never consumed.

**Worst Offenders:**

| File | Count | Examples |
|------|-------|----------|
| `src/components/DashboardView.tsx` | 20+ | `Languages`, `Rocket`, `Shield`, `Bug`, `Sparkles`, `Database`, `Network`, `Settings`, `BarChart3`, `Library`, `Puzzle`, `Play`, `Terminal`, `RefreshCw`, `Download`, `Upload`, `Eye`, `Folder`, `GitBranch`, `GitMerge`, `Copy`, `Layers`, `Wrench`, `Filter`, `LayoutGrid`, `BookOpen` |
| `src/main.ts` | 10+ | Unused catch vars (`err`, `e`), empty catch block, unused assignments |
| `src/components/jpe-error-handling.tsx` | 6 | `err`, `e` in catch blocks (not prefixed with `_`) |
| Various components | 40+ | Unused state setters, dialog states, imports |

**Impact:** ESLint fails → `npm run build` may fail in CI.

**Fix:** 
- Remove unused imports entirely
- Prefix unused catch vars with `_`: `catch (_err)`
- Prefix unused params with `_`: `function handler(_data)`

### 1.2 React Hooks Rule Violation (1 issue)

**Location:** Unknown component, line 52:17  
**Error:** `React.useMemo` called conditionally (after early return)  
**Impact:** Production crashes

**Fix:**
```tsx
// ❌ WRONG
if (!data) return null
const processed = React.useMemo(() => ..., [data])

// ✅ CORRECT
const processed = React.useMemo(() => {
  if (!data) return null
  return /* logic */
}, [data])
```

## 2. Architecture Audit

### 2.1 Service Layer (70+ Classes)

**✅ Strengths:**
- Clear separation of concerns
- Singleton pattern used correctly
- AI services properly extend `BaseAIService`
- Retry logic implemented in `BaseAIService`

**⚠️ Concerns:**

| Service | Lines | Issue | Recommendation |
|---------|-------|-------|----------------|
| `OllamaService.ts` | 1,073 | God object | Split into `OllamaClient`, `OllamaPromptEngine`, `OllamaResponseParser` |
| `CompilerService.ts` | ~600 | 12+ dependencies | Add facade pattern |
| `ProjectService.ts` | ~400 | Mixed concerns | Separate file ops from project mgmt |

**Recommended Interface:**
```typescript
interface IAIService {
  chat(messages: AIMessage[]): Promise<AIResult>
  stream(messages: AIMessage[]): AsyncIterable<AIResult>
  validateConfig(): boolean
}
```

### 2.2 State Management (23 Stores)

**✅ Strengths:**
- Zustand patterns correct (immutable updates)
- Proper use of selectors

**⚠️ Concerns:**
- Store sprawl — 23 stores for single app
- Cross-store dependencies complex:
  - `useProjectStore` → `useActivityStore` → `useEditorStore`

**Recommended Consolidation:**
- Merge `useGamepadInput`, `useGamepadEditing`, `useGamepadCoding` → `useGamepadStore`
- Merge `useKeyboardNavigation`, `useKeyboardShortcuts` → `useInputStore`
- Merge `useTelemetryStore` + `useActivityStore` → `useAnalyticsStore`

### 2.3 Hooks Layer (18 Custom Hooks)

**✅ Good:** Proper cleanup, `useCallback`/`useMemo` used correctly

**⚠️ Issues:**
- `useWorkerPool.ts` (161 lines) — too complex for hook
- `useTelemetry.ts` (91 lines) — should be service, not hook
