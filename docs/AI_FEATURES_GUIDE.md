# JPE Studio AI Features Guide 🤖

JPE Studio leverages Google Gemini 1.5 Pro/Flash to provide a suite of intelligent tools that help you create, debug, and optimize your Sims 4 mods more efficiently.

## 1. Setting Up Your AI Assistant

To enable AI features, you need a Google Gemini API key:

1.  Visit the [Google AI Studio](https://aistudio.google.com/app/apikey) to get a free API key.
2.  In JPE Studio, go to **Settings** → **AI Assistant**.
3.  Paste your API key into the field.
4.  Click **Test Connection** to verify.
5.  Your key is stored securely using industry-standard encryption.

## 2. Key Features

### 🚀 Smart Code Completion
As you type in the code editor, JPE Studio predicts the next property or value based on the context of your mod.
- **Usage**: Automatically appears as you type.
- **Trigger**: Press `Tab` or `Enter` to accept a suggestion.

### 💬 Unified AI Assistant (Ctrl+K)
Access a global chat interface anywhere in the app to ask questions about your project or get general modding help.
- **Shortcut**: `Ctrl + K`
- **Capabilities**:
    - "Explain the current error in this file"
    - "Optimize the interaction logic"
    - "How do I create a buff that triggers on social events?"

### 🔧 One-Click Auto-Fix
When the diagnostics panel identifies an issue, the AI can often fix it for you automatically.
- **Usage**: Click the **Auto-Fix** button next to an error.
- **Workflow**: Review the **Diff Preview** to see exactly what will change, then click **Apply**.

### 📝 Natural Language to JPE (//)
Write what you want in plain English, and the AI will convert it into valid JPE code.
- **Usage**: Type `//` followed by your description.
- **Example**: `// create a social interaction that gives a happy buff`
- **Result**: Generates the full interaction and buff block instantly.

### 📊 Dashboard Insights & Health
The dashboard provides a high-level overview of your project's quality.
- **Mod Health Gauge**: A real-time score (0-100%) based on errors, consistency, and complexity.
- **AI Insights Card**: Strategic tips and warnings generated by analyzing your entire project.

## 3. Best Practices

-   **Use Context**: The AI works best when your interaction and buff IDs are descriptive.
-   **Review Fixes**: Always use the **Diff Preview** before applying an auto-fix to ensure the logic matches your intent.
-   **Local Fallback**: If you lose internet connection, JPE Studio will automatically switch to a local (offline) predictive engine for basic completions.

## 4. Privacy & Security

-   **Anonymization**: JPE Studio strips local file paths and personal identifiers before sending code snippets to the Gemini API.
-   **Opt-in**: You can disable all remote AI features at any time in the Settings menu.
