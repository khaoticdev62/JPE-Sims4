# AI Features - Quick Reference

## Keyboard Shortcuts
```
Ctrl+K       Open AI Assistant Panel
Ctrl+Space   Code Completion
Ctrl+,       Open Settings
Ctrl+Z       Undo Fix
Esc          Close AI Panel
```

## Main Features

### 1. AI Assistant Panel (Ctrl+K)
- Type to search actions
- ↑↓ to navigate, Enter to select
- Esc to close
- Shows high-priority fixes first

### 2. Code Completion (Ctrl+Space)
- Auto-suggests as you type
- Tab/Enter to accept
- Esc to dismiss
- Works with context awareness

### 3. Error Explanation
- Hover over error squiggle
- See tooltip with explanation
- Get quick fix suggestions
- Learn why error occurred

### 4. Auto-Fix
- Search in AI Assistant (Ctrl+K)
- Preview changes before applying
- Click "Apply" to execute
- Undo with Ctrl+Z if needed

### 5. Code Health Monitor
- Shows in Dashboard
- Ranges from 0-100%
- Color coded: Green (good) → Red (bad)
- Updates in real-time

### 6. AI Insights
- Recent suggestions in Dashboard
- Shows improvements made
- Timestamps and categories
- Click for more details

## Quick Workflows

### Fix an Error
```
1. Hover over error → Read explanation
2. Ctrl+K → Type "fix"
3. Select fix action → Preview changes
4. Click "Apply" → Done!
```

### Get Code Completion
```
1. Start typing partial code
2. Ctrl+Space (or wait for auto-suggest)
3. Tab/Enter to accept suggestion
4. Continue coding
```

### Monitor Code Quality
```
1. Open Dashboard (Home tab)
2. Check Health Gauge (percentage and color)
3. See Errors/Warnings/Suggestions counts
4. Click for detailed metrics
```

### Apply Multiple Fixes
```
1. Ctrl+K → Filter fixes (type "fix")
2. Select first fix → Apply
3. Repeat for other high-priority fixes
4. Check health gauge improved
```

## Settings Location
Settings → AI Features

### Key Settings
- **API Key** - Your Gemini API key
- **Model** - Choose FLASH (fast) or PRO (powerful)
- **Offline Mode** - Use local AI only
- **Rate Limit** - Requests per minute
- **Test Connection** - Verify API is working

## Error Priority
```
🔴 CRITICAL (Errors)
⚠️  WARNING (Warnings)
💡 INFO (Suggestions)
```

## Health Score Interpretation
```
🟢 90%+ = Excellent   (All clear!)
🟡 70-89% = Good      (Few issues)
🟠 50-69% = Fair      (Some problems)
🟠 30-49% = Poor      (Major issues)
🔴 <30% = Critical    (Fix immediately!)
```

## Common Issues

| Problem | Solution |
|---------|----------|
| No completions | Check API key, test connection |
| Slow responses | Switch to FLASH model |
| AI panel won't open | Try restarting, check keyboard |
| Fix didn't work | Undo (Ctrl+Z), try manual fix |
| Health won't update | Refresh with F5 or close/reopen |

## Pro Tips

- 📊 Check health gauge daily
- 💾 Undo with Ctrl+Z if unsure
- 🔐 Keep API key confidential
