## Getting Started

### Q: I've never done this before. Can I actually do this?
**A:** 100% yes! JPE Studio is designed for complete beginners. You don't need:
- Programming knowledge
- Translation experience
- Technical skills
- Understanding of how mods work

You just need:
- A mod you want to translate
- 10-15 minutes
- Willingness to try

We've had 5-year-olds help translate mods (with guidance). If a 5-year-old can do it, so can you! 😄

---

### Q: What do I need to install?
**A:** Just two things:
1. **Python** (if you don't have it) - [Easy installer](./PYTHON_SETUP.md)
2. **JPE Studio** - `pip install jpe-sims4-studio`

That's it! No other software needed.

---

### Q: How do I get started?
**A:** [Getting Started Guide](./GETTING_STARTED_DESKTOP.md) walks you through step-by-step with pictures. It takes about 15 minutes.

**TL;DR:**
1. Install JPE Studio
2. Type `jpe-studio`
3. Click "Load Mod"
4. Translate some text
5. Click "Build"
6. Done! 🎉

---

### Q: Is this free?
**A:** Yes! JPE Studio is completely free and open-source. No ads, no premium features, no hidden costs.

We do this because we love the modding community! 💜

## About Translations

### Q: What language can I translate to?
**A:** Any language! We support:
- Common languages (Spanish, French, German, Chinese, Japanese, etc.)
- Less common languages (Icelandic, Basque, Welsh, etc.)
- Right-to-left languages (Arabic, Hebrew, Urdu, etc.)

**Can't find your language?** Message us on [Discord](https://discord.gg/jpe) and we'll add support!

---

### Q: Do I have to translate the ENTIRE mod?
**A:** Nope! Translate as much or as little as you want:
- **10% translated?** Great! Players get something
- **50% translated?** Awesome!
- **100% translated?** Amazing!

Partial translations are 100% valid. Every bit helps! 🌍

---

### Q: What if my translation isn't perfect?
**A:** That's okay! Here's the cool part:
- Your translation gets shared
- Players (and other translators) can improve it
- Everyone benefits
- No judgment

Translation is a community effort. Your contribution matters, even if it's not perfect! 👍

---

### Q: Can I use Google Translate?
**A:** You *can*, but we don't recommend it for the whole thing. Here's why:
- Google Translate makes mistakes
- Context gets lost
- Idioms don't translate well

**Better approach:**
- Use Google Translate as a starting point
- Fix the obvious errors
- Have a native speaker review if possible

**Pro Tip:** Google Translate is great for getting an idea of what the text means. Use your brain for the actual translation. 🧠

---

### Q: Can I translate this to multiple languages?
**A:** Absolutely! You can:
- Translate one mod to Spanish
- Then translate the same mod to French
- Then to German
- Each version is separate

You could even have a team where each person translates to their native language! 🌐

---

### Q: What if the AI suggestions are wrong?
**A:** That's totally fine! Here's what to do:
1. Look at the suggestion
2. If it's good, click it
3. If it's bad, ignore it and type your own

**The AI is a helper, not a replacement.** You're in control. Always. 💪

## Technical Questions

### Q: Will this break my mod?
**A:** No! Here's why:
- We never modify your original mod
- We validate everything before building
- If something's wrong, we tell you
- You always have a backup of your original

**Bottom line:** Your original mod is 100% safe, guaranteed.

---

### Q: What file format is my mod?
**A:** It could be either:
- **Folder** - A directory with mod files
- **.zip file** - A compressed archive (like a .rar file)

JPE Studio handles both! Just pick whichever you have.

**Don't know which?** Both work the same way. Pick one and try! 🎯

---

### Q: Can I use this on Mac/Linux?
**A:** Yes! JPE Studio works on:
- ✅ Windows (all versions)
- ✅ Mac (Intel and Apple Silicon)
- ✅ Linux (Ubuntu, Fedora, Debian, etc.)

Same commands, works the same way! 🖥️

---

### Q: Do I need an internet connection?
**A:** For most features: **No!**

JPE Studio works offline:
- Load mods ✅
- Translate ✅
- Build translated versions ✅
- Export ✅

**One exception:** AI suggestions need internet (but it's optional).

---

### Q: Can I use this with mods I didn't create?
**A:** Absolutely! You can translate:
- Your own mods
- Other people's mods
- Community mods
- Any mod, really

**Note:** If you're translating someone else's mod, it's nice to:
- Ask permission first (if possible)
- Share your translation with the original creator
- Credit them in your translation

But it's not required! The modding community is awesome and shares everything. 🤝

---

### Q: Can multiple people work on the same translation?
**A:** Yes! Here's how:
1. One person loads the mod in JPE Studio
2. They translate some segments
3. They share the project file with another translator
4. That person opens the same file
5. They translate different segments
6. When done, combine the work
7. Build the final version

[Full Team Collaboration Guide](./TEAM_COLLABORATION.md)

---

### Q: What if someone else already translated this mod?
**A:** You have options:
1. **Start fresh** - Translate your own version
2. **Use theirs as a starting point** - Import their work and improve it
3. **Create a variant** - Translate to a different language
4. **Combine efforts** - Work together to improve coverage

The modding community loves collaboration! 🌟

## Common Issues

### Q: JPE Studio won't open
**A:** Try these in order:
1. Close any existing windows
2. Open a fresh Command Prompt
3. Type `jpe-studio` again
4. Wait 10 seconds (it's loading)

Still not working? [Troubleshooting Guide](./TROUBLESHOOTING.md)

---

### Q: My mod won't load
**A:** Common causes:
- **File is corrupted** - Try downloading again
- **File is named wrong** - Make sure it ends in .zip or has mod files inside
- **Permissions issue** - Try moving to Desktop and trying again
- **Wrong file type** - Make sure it's actually a mod (not a texture pack, etc.)

[More solutions](./TROUBLESHOOTING.md)

---

### Q: Build failed / Error message
**A:** This happens sometimes! Here's what to do:
1. Read the error message (it usually says what's wrong)
2. Try building again
3. Check [Troubleshooting](./TROUBLESHOOTING.md) for your specific error
4. Ask [Discord](https://discord.gg/jpe) for help

**Don't panic!** Build errors are usually easy to fix. 🆘

---

### Q: My translation looks weird in the game
**A:** Possible causes:
- **Text is too long** - Try shortening it
- **Special characters broke** - Use simpler punctuation
- **Encoding issue** - Try re-typing it

**Pro tip:** Use the Preview feature before building to catch these!

---

### Q: I accidentally deleted my translation
**A:** Don't panic! Try:
1. **Undo** (Ctrl+Z) - Usually works!
2. **Check backups** - JPE Studio auto-saves
3. **Restart the app** - Last saved version loads
4. **Load a backup** - If you saved multiple versions

[Data Recovery Help](./TROUBLESHOOTING.md#accidentally-deleted-stuff)
