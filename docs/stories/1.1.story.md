# Story 1.1: Create a New Mod Project

**Status**: ✅ Done - Ready for QA

---

## Story

**As a** mod creator,  
**I want to** create a new project with initial folder structure,  
**so that** I can organize my mod files.

---

## Acceptance Criteria

1. User can click "New Project" in menu
2. Dialog prompts for project name
3. User selects folder location on disk
4. App creates project structure:
   - project.json (metadata)
   - /mods/ folder (for mod files)
   - /.jpe_history/ folder (for version history)
5. Success message shows project path
6. Project opens in editor immediately

### Data Models

**Project Interface** [Source: architecture/ARCHITECTURE.md#339]
```typescript
interface Project {
  id: string;
  name: string;
  rootPath: string;
  files: ModFile[];
  metadata: ProjectMetadata;
}
```

**Project Store Interface** [Source: architecture/ARCHITECTURE.md#347]
```typescript
interface ProjectStore {
  // State
  currentProject: Project | null;
  recentProjects: Project[];

  // Actions
  createProject: (name: string, path: string) => Promise<void>;
  openProject: (path: string) => Promise<void>;
  saveProject: () => Promise<void>;
  addFile: (project: Project, file: ModFile) => Promise<void>;
  removeFile: (project: Project, fileId: string) => Promise<void>;
}
```

**ProjectService Interface** [Source: architecture/ARCHITECTURE.md#573]
```typescript
class ProjectService {
  // Create new project
  async createProject(name: string, rootPath: string): Promise<Project>;

  // Load existing project
  async openProject(rootPath: string): Promise<Project>;

  // Save project metadata
  async saveProject(project: Project): Promise<void>;

  // Manage files
  async addFile(project: Project, filePath: string): Promise<ModFile>;
  async removeFile(project: Project, fileId: string): Promise<void>;
  async renameFile(project: Project, fileId: string, newName: string): Promise<void>;
}
```

### Project Service Implementation Details

**Validation rules for project name** (from epic requirements):
- Must be alphanumeric
- No spaces (use underscores or hyphens)
- Should be unique within recent projects list

**project.json structure** (inferred from Project interface):
```json

  "id": "uuid-v4",
  "name": "project-name",
  "rootPath": "/path/to/project",
  "files": [],
  "metadata": {
    "createdAt": "ISO-8601 timestamp",
    "updatedAt": "ISO-8601 timestamp",
    "version": "1.0.0"
  }
}
```

### IPC Communication Pattern [Source: architecture/ARCHITECTURE.md#885]

**Main Process (src/main.ts):**
```typescript
ipcMain.handle('dialog:openFolder', async () => {
  const result = await dialog.showOpenDialog({
    properties: ['openDirectory']
  });
  return result.filePaths[0] || null;
});

ipcMain.handle('project:create', async (event, { name, rootPath }) => {
  const project = await projectService.createProject(name, rootPath);
  return project;
});
```

**Preload Script (src/preload.ts):**
```typescript
contextBridge.exposeInMainWorld('electronAPI', {
  openFolderDialog: () => ipcRenderer.invoke('dialog:openFolder'),
  createProject: (name: string, rootPath: string) => 
    ipcRenderer.invoke('project:create', { name, rootPath }),
});
```
