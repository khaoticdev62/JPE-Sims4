### Technical Constraints

- **Electron dependency**: FileService.openFolder() and FileService.openFile() require Electron. Tests must mock these.
- **File system**: File discovery uses `FileService.listDirectory()` which also requires Electron. Unit tests should mock FileService.
- **Recent projects**: Stored in Zustand store, persisted to `safeStorage`. Tests should mock storage.
- **No breaking changes**: All existing functionality (Story 1.1, 1.2) must remain intact.

### Testing Standards

**Unit Tests** (Jest + React Testing Library):
- Mock all Electron IPC calls (FileService, window.electron)
- Mock Zustand stores (useProjectStore, useEditorStore)
- Use `render`, `screen`, `fireEvent`, `waitFor` from @testing-library/react
- Follow arrange-act-assert pattern
- Test both success and error paths

**E2E Tests** (Playwright):
- Start Next.js dev server before tests
- Create test project directories in temp folder
- Clean up test files after each test
- Assert on UI state (file tree, editor tabs, dialogs)
