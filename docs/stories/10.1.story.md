# Story 10.1: Audio Scrubbing Utility

## Story

**As a** Modder,
**I want** my workspace to provide auditory feedback reflecting my project health,
**so that** I can sense errors even when not looking at the diagnostics panel.

---

## Acceptance Criteria

1. **Spectral Success Chords** — Reactive audio on successful compilation or code scrubbing
2. **Diagnostic Hums** — Low-frequency hums scale with error density
3. **<50ms Audio Latency** — Audio response time imperceptible
4. **Dynamic Frequency Shift** — Audio shifts based on current error density
5. **Tests** — Unit tests for audio engine; integration test for latency verification

---

## Tasks / Subtasks

### **Task 1**: Audio Engine

Create the core audio playback system.

- [ ] **Subtask 1.1**: Create `AudioEngine` service
  - Load and cache audio samples (success chord, error hum, scrub click)
  - Play sounds on demand with low latency
  - Volume control (master + per-sound)
  - Mute toggle

- [ ] **Subtask 1.2**: Audio asset bundling
  - Bundle audio files with application
  - Supported formats: WAV, OGG
  - Preload on app start for instant playback

---

### **Task 2**: Scrub Sound Generator

Audio feedback for scrolling/typing.

- [ ] **Subtask 2.1**: Create `ScrubSoundGenerator`
  - Play soft mechanical click on scroll events
  - Debounce to avoid audio spam (max 10 clicks/second)
  - Pitch varies slightly based on scroll direction

- [ ] **Subtask 2.2**: Success chord
  - Play on successful compilation
  - 1.5-second decaying Teal-branded chime
  - Non-intrusive but noticeable

---

### **Task 3**: Error Density Audio

- [ ] **Subtask 3.1**: Create `ErrorDensityAudio`
  - Subscribe to validation results
  - Map error count to audio frequency
  - Low hum for high error density
  - Silence or pleasant tone for clean code

- [ ] **Subtask 3.2**: Audio feedback mapping
  - 0 errors: Silence or soft ambient
  - 1-3 errors: Subtle low hum
  - 4-10 errors: Noticeable amber hum
  - 10+ errors: Prominent red hum

---

### **Task 4**: Tests

- [ ] **Subtask 4.1**: Unit tests for AudioEngine
  - Sounds load and play correctly
  - Volume control works
  - Mute silences all audio

- [ ] **Subtask 4.2**: Latency test
  - Trigger sound → measure playback delay
  - Verify <50ms latency

- [ ] **Subtask 4.3**: Integration test
  - Type in editor → scrub sounds play
  - Compile success → success chord plays
  - Introduce errors → error hum scales with count

## Dev Notes

### Web Audio API

Use Web Audio API for low-latency playback:
```typescript
const audioContext = new AudioContext();
const buffer = await loadAudioBuffer('success-chord.wav');
const source = audioContext.createBufferSource();
source.buffer = buffer;
source.connect(audioContext.destination);
source.start();
```
