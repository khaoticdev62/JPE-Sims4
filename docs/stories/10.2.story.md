# Story 10.2: Haptic Heartbeat Integration

## Story

**As a** Modder using a Steam Deck or controller,
**I want** subtle haptic feedback for background task completion,
**so that** I know when a massive project has finished compiling while focused elsewhere.

---

## Acceptance Criteria

1. **Haptic Pulses on Completion** — Specific heartbeat pattern indicates success
2. **Steam Deck/Controller Support** — Works with Steam Input, XInput controllers
3. **Industrial Isolation Protocol** — Vibration intensity prevents user fatigue
4. **Configurable Intensity** — User controls haptic strength via sensory master slider
5. **Tests** — Unit tests for haptic engine; manual test for device compatibility

---

## Tasks / Subtasks

### **Task 1**: Haptic Engine

Create the haptic feedback service.

- [ ] **Subtask 1.1**: Create `HapticEngine` service
  - Detect connected haptic devices (Steam Deck, Xbox controller, etc.)
  - Send vibration commands with specified intensity and duration
  - Support multiple device APIs (Gamepad API, Steam Input)

- [ ] **Subtask 1.2**: Haptic patterns
  - **Success heartbeat**: Two short pulses (like "da-dum")
  - **Error alert**: Single long pulse
  - **Progress**: Gentle rumble during long operations
  - **Notification**: Soft tap for minor events

---

### **Task 2**: Device Detection & Abstraction

Abstract across different haptic device APIs.

- [ ] **Subtask 2.1**: Create `HapticDeviceDetector`
  - Detect connected gamepads via Gamepad API
  - Identify device type (Steam Deck, Xbox, etc.)
  - Select appropriate haptic API per device

- [ ] **Subtask 2.2**: Haptic API abstraction
  - **Steam Input**: Precise trackpad haptics (if available)
  - **Gamepad Vibration**: Standard dual-motor vibration
  - Fallback: No haptic (graceful degradation)

---

### **Task 3**: Event-Driven Haptics

Wire haptic feedback to application events.

- [ ] **Subtask 3.1**: Build completion haptic
  - When build finishes successfully → success heartbeat
  - When build fails → error alert pulse
  - During long builds → gentle progress rumble

- [ ] **Subtask 3.2**: Industrial Isolation Protocol
  - Max vibration duration: 500ms (prevent fatigue)
  - Cooldown between haptics: 2 seconds
  - Intensity scales with master slider
  - Auto-disable after repeated triggers (fatigue prevention)

---

### **Task 4**: Tests

- [ ] **Subtask 4.1**: Unit tests for HapticEngine
  - Vibration commands sent correctly
  - Patterns play as defined
  - Intensity scaling works

- [ ] **Subtask 4.2**: Unit tests for HapticDeviceDetector
  - Detects connected gamepads
  - Selects correct API per device
  - Handles no-device gracefully

- [ ] **Subtask 4.3**: Manual device testing
  - Steam Deck: haptic feedback works
  - Xbox controller: vibration works
  - No controller: no errors

## Dev Notes

### Gamepad Vibration API

```typescript
const gamepad = navigator.getGamepads()[0];
if (gamepad?.vibrationActuator) {
  gamepad.vibrationActuator.playEffect('dual-rumble', {
    startDelay: 0,
    duration: 200,
    weakMagnitude: 0.5,
    strongMagnitude: 0.3,
  });
}
```

### Steam Input Haptics

Steam Deck supports more precise haptics via Steamworks SDK (requires native layer). For Electron, use Gamepad API as baseline.
