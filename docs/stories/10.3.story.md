# Story 10.3: Bioluminescent Visual Bridges

## Story

**As a** Modder,
**I want** my UI to visually pulse in sync with system events,
**so that** the brand feels alive and I can sense system state at a glance.

---

## Acceptance Criteria

1. **Spectral Pulse Animations** — UI elements emit bioluminescent glows on events
2. **Severity-Mapped Colors** — Teal for success, amber for warnings, red for errors
3. **200-400ms Motion Curve** — All animations follow standard brand timing
4. **Glow Intensity Mapping** — Glow strength maps to event severity
5. **Tests** — Unit tests for animation controller; visual regression tests

---

## Tasks / Subtasks

### **Task 1**: Pulse Animation System

Create the animation engine for bioluminescent effects.

- [ ] **Subtask 1.1**: Create `PulseAnimationController`
  - Trigger pulse animations on events
  - CSS animation with 200-400ms ease timing
  - Support multiple simultaneous pulses (queue/rate-limit)
  - Configurable intensity

- [ ] **Subtask 1.2**: Pulse types
  - **Border pulse**: Element border glows and fades
  - **Background pulse**: Subtle background glow
  - **Icon pulse**: Icons briefly illuminate
  - **Shadow pulse**: Drop shadow intensifies

---

### **Task 2**: Event-to-Pulse Mapping

Define which events trigger which pulses.

- [ ] **Subtask 2.1**: Create `EventPulseMapper`
  - Subscribe to application events
  - Map event to pulse type and color
  - **Build success**: Teal border pulse on editor
  - **Build error**: Red shadow pulse on diagnostics
  - **File saved**: Subtle background pulse
  - **Link synced**: Teal icon pulse on bridge status

- [ ] **Subtask 2.2**: Color mapping
  - Teal (#2EC4B6): Success, health, sync
  - Amber (#FFAA00): Warning, high complexity
  - Red (#FF4444): Error, critical failure
  - Violet (#8B5CF6): Active ingestion
  - Gray (#6B7280): Null/disconnected

---

### **Task 3**: CSS Implementation

Implement the visual effects.

- [ ] **Subtask 3.1**: CSS animations
  - Keyframe animations for pulse effects
  - Box-shadow transitions for glow
  - Border-color transitions
  - Opacity fades

- [ ] **Subtask 3.2**: Performance optimization
  - GPU-accelerated animations (transform, opacity)
  - No layout thrashing during animations
  - Throttle pulses during rapid events

---

### **Task 4**: Tests

- [ ] **Subtask 4.1**: Unit tests for PulseAnimationController
  - Pulse triggered on events
  - Animation timing correct
  - Rate limiting works

- [ ] **Subtask 4.2**: Visual regression tests
  - Pulse appearance matches design spec
  - Colors correct per severity
  - Animation smooth (no jank)

### CSS Pulse Animation

  0% { box-shadow: 0 0 0 0 rgba(46, 196, 182, 0); }
