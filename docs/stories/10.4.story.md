# Story 10.4: Master Sensory Control Hub

## Story

**As a** Modder,
**I want** full control over audio and haptic feedback intensity from a single settings panel,
**so that** I can customize the sensory experience to my preferences and environment.

---

## Acceptance Criteria

1. **Sensory Master Slider** — Global slider scales both audio volume and haptic intensity
2. **Independent Toggle Controls** — Audio, haptics, and visual pulses can be toggled independently
3. **OS Quiet Mode Respect** — App automatically mutes when OS Quiet/Focus mode is active
4. **Persistent Preferences** — Sensory settings saved and restored across sessions
5. **Tests** — Unit tests for sensory controller; integration test for Quiet Mode detection

---

## Tasks / Subtasks

Create the master control service.

- [ ] **Subtask 1.1**: Create `SensoryController` service
  - Master volume slider (0-100%)

### **Task 3**: OS Quiet Mode Detection

Respect system focus/quiet settings.

- [ ] **Subtask 3.1**: Create `QuietModeDetector`
  - Detect macOS Focus Mode
  - Detect Windows Do Not Disturb / Quiet Hours
  - Detect Steam Deck Quiet Mode
  - Auto-mute sensory output when active

- [ ] **Subtask 3.2**: Quiet mode behavior
  - Audio: Auto-mute (visual indicator shows why)
  - Haptics: Reduce to minimum (don't fully disable)
  - Visual pulses: Continue (non-disruptive)
  - Notification: "Sensory muted: Quiet Mode active"

## Dev Notes

### OS Quiet Mode Detection

**macOS:** Use `defaults read com.apple.controlcenter FocusModes`
**Windows:** Check registry for Focus Assist settings
**SteamOS:** Check Steam Input quiet mode flag

For Electron, use platform-specific shell commands or native modules.
