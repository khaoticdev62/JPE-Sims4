### STBL File Format (Sims 4)

Binary format:
- Header: magic number, version, string count
- Per-language blocks: language code (4 bytes), entry count, entries
- Per entry: string hash (4 bytes), string length (2 bytes), UTF-16 string data

Language codes: `0x00000000` (EN), `0x00000001` (DE), `0x00000002` (FR), `0x00000003` (ES), `0x00000004` (IT), `0x00000005` (NL), `0x00000006` (SV), `0x00000007` (DA), `0x00000008` (NO), `0x00000009` (FI), `0x0000000A` (PT), `0x0000000B` (RU), `0x0000000C` (PL), `0x0000000D` (CZ), `0x0000000E` (KO), `0x0000000F` (ZH_TW), `0x00000010` (JA), `0x00000011` (ZH_CN)
