# Story 2.1.2: Read Python/TypeScript Script Files

**Status**: Done - Ready for QA

---

## Story

**As a** technical mod creator,
**I want to open .py and .ts4script files and see their structure in JPE format,
**so that** I can understand and edit script-based mods.

---

## Acceptance Criteria

1. **Open Python Files** — Clicking a `.py` file opens it with decompiled JPE view
2. **Open TS4Script Files** — Clicking a `.ts4script` file opens with decompiled JPE view
3. **Function Definitions Shown** — Classes, methods, and functions displayed clearly in JPE
4. **Comments Preserved** — Docstrings shown as JPE descriptions
5. **Python Syntax Highlighting** — Monaco editor uses Python language mode for .py files
6. **Round-Trip Safety** — Saving preserves original Python source (JPE is read-only view)
7. **Tests** — Unit tests for parser, decompiler, and round-trip
