# Story 2.3: JPE Grammar & Syntax Highlighting Engine

## Story

**As a** Modder,
**I want** the editor to understand WHEN/DO/ONLY_IF JPE keywords and provide syntax highlighting,
**so that** I can write mod logic with clear visual structure and catch syntax errors early.

---

## Acceptance Criteria

1. **Keyword Highlighting** — JPE keywords (WHEN, DO, ONLY_IF, CONDITIONS, AND, OR, NOT) rendered with distinct spectral colors
2. **Logical Block Indentation** — Nested blocks auto-indent with visual guides (vertical lines showing block scope)
3. **Syntax Error Detection** — Invalid JPE syntax flagged with red squiggly underlines in real-time
4. **Logical Summary in Status Bar** — Status bar shows current block context (e.g., "Inside WHEN: interaction test > ONLY_IF: buff check")
5. **Auto-Complete for Keywords** — Typing "W" suggests "WHEN", "WHILE"; selecting inserts with proper structure
6. **Tests** — Unit tests for lexer, syntax highlighter, and keyword parser; integration test with sample JPE files

## Dev Notes

### JPE Syntax Reference

JPE (Just Plain English) syntax structure:
```
WHEN <condition> DO
  <action>
  ONLY_IF <additional_condition>
    <nested_action>
  END
END
```

Keywords are case-insensitive. Conditions can be logical expressions. Actions reference Sims 4 tuning IDs or named interactions.
