# Story 2.4: XML Pretty-Printer & Namespace Validator

## Story

**As a** Modder,
**I want** the final XML output to be formatted with proper indentation and valid namespaces,
**so that** it meets Sims 4 modding standards and is readable for manual inspection.

---

## Acceptance Criteria

1. **Pretty-Printed Output** — XML formatted with 2-space indentation, consistent line breaks ✅
2. **UTF-8 Header** — All XML files include `<?xml version="1.0" encoding="UTF-8"?>` declaration ✅
3. **Namespace Validation** — All Sims 4 tuning namespaces declared correctly (`xmlns:t="..."`) ✅
4. **Auto-Namespace Fix** — Missing namespaces auto-inserted during compilation ✅
5. **Tests** — Unit tests for pretty-printer and namespace validator; integration test with real XML mods ✅
