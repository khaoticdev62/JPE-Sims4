# Story 3.1: Debounced "As-You-Type" Validation

## Story

**As a** Modder,
**I want** errors highlighted while I type with a smooth debounce delay,
**so that** I can fix issues in real-time without manual compilation or UI stutter.

---

## Acceptance Criteria

1. **300ms Debounce** — Validation triggers 300ms after last keystroke (not on every key)
2. **Syntax Errors** — Red squiggly underlines in Monaco editor for syntax errors
3. **Semantic Warnings** — Yellow squiggly underlines for semantic issues (undefined references)
4. **Status Bar Updates** — Real-time error/warning count in workspace status bar
5. **No UI Blocking** — Typing remains fluid at 60fps during validation
6. **Tests** — Unit tests for debounce logic, validation engine; integration test verifying typing performance

---

## Dev Notes

### Debounce Strategy

```
Type...Type...Type...[300ms idle]→ Validate
Type...Type...[200ms]Type...[300ms idle]→ Validate (first cancelled)
```

Use `setTimeout`/`clearTimeout` for debounce. Consider `requestIdleCallback` for non-urgent validation.
