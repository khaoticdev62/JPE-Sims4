# Story 3.2: Synchronized Live XML Preview

## Story

**As a** Modder,
**I want** a side-by-side XML preview that updates in real-time as I edit JPE,
**so that** I can see the final mod structure instantly without switching contexts.

---

## Acceptance Criteria

1. **Live Preview Panel** — Toggleable right panel showing XML translation of current JPE file
2. **<200ms Update Latency** — Preview re-renders within 200ms of JPE change
3. **Synchronized Scrolling** — Scrolling in JPE editor syncs scroll position in XML preview
4. **Pretty-Printed XML** — Preview shows formatted XML with syntax highlighting
5. **Error Overlay** — Invalid JPE shows error location in preview panel
6. **Tests** — Unit tests for sync scroll logic; integration test for preview update latency

---

### **Task 2**: Synchronized Scrolling

Implement scroll synchronization between JPE editor and XML preview.

- [ ] **Subtask 2.1**: Scroll position mapping
  - Map JPE line number to corresponding XML line number
  - Handle 1-to-N mapping (one JPE line → multiple XML lines)
  - Calculate scroll percentage and apply to other pane

- [ ] **Subtask 2.2**: Bidirectional sync
  - Scroll in JPE editor → XML preview follows
  - Scroll in XML preview → JPE editor follows
  - Prevent feedback loops (ignore programmatic scroll events)

- [ ] **Subtask 2.3**: Sync toggle
  - Enable/disable sync with button
  - Visual indicator when sync is active
  - Remember user preference

---

### **Task 3**: Performance Optimization

Ensure preview updates don't impact typing performance.

- [ ] **Subtask 3.1**: Debounced translation
  - Only re-translate after 200ms of idle typing
  - Show "Updating..." indicator during translation
  - Cancel pending translation on new input

- [ ] **Subtask 3.2**: Virtual rendering for large XML
  - Use Monaco's virtual scrolling for large XML files
  - Only render visible lines
  - Smooth scroll performance at 60fps

## Dev Notes

### Scroll Synchronization Strategy

JPE and XML have different line counts. Use logical position mapping:
- Track current JPE block/element
- Map to corresponding XML element range
- Scroll to keep mapped position at same viewport percentage

Alternative: use scroll percentage (simpler but less precise):
- JPE scroll 30% from top → XML preview scrolls 30% from top
