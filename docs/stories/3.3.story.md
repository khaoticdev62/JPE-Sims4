# Story 3.3: Diagnostics Panel UI

## Story

**As a** Modder,
**I want** a dedicated panel listing all errors, warnings, and info items across my project,
**so that** I can efficiently triage and fix issues without hunting through code.

---

## Acceptance Criteria

1. **Categorized List** — Issues grouped by Errors, Warnings, Info with collapsible sections
2. **Detailed Descriptions** — Each issue shows message, file, line, column
3. **Click-to-Navigate** — Clicking an issue jumps editor cursor to exact location
4. **Filter & Search** — Filter by severity, search by keyword, filter by file
5. **Real-Time Updates** — Panel updates as validation runs (no manual refresh)
6. **Tests** — Unit tests for panel component; integration test for click-to-navigate

---

## Tasks / Subtasks

### **Task 1**: Diagnostics Panel Component

Create the main diagnostics list UI.

- [ ] **Subtask 1.1**: Create `DiagnosticsPanel` component
  - Display grouped list: Errors (red), Warnings (amber), Info (blue)
  - Each item: icon, message, file name, line:column
  - Collapsible sections per category
  - Empty state: "No issues found ✓" with green checkmark

- [ ] **Subtask 1.2**: Item rendering
  - Truncate long messages with ellipsis
  - Hover tooltip shows full message
  - File badge for multi-file projects

---

### **Task 2**: Click-to-Navigate

Wire click handlers to jump editor to issue location.

- [ ] **Subtask 2.1**: Navigation logic
  - Click issue → open corresponding file if not open
  - Move cursor to line:column
  - Highlight the problematic range
  - Focus editor pane

- [ ] **Subtask 2.2**: Keyboard navigation
  - Arrow keys navigate through issue list
  - Enter opens issue location
  - Escape closes panel

---

### **Task 3**: Filtering & Search

- [ ] **Subtask 3.1**: Filter controls
  - Severity toggle buttons (show/hide errors, warnings, info)
  - Search input filters issues by message content
  - File dropdown filters to single file
  - "Follow Active Editor" toggle (show only current file issues)

- [ ] **Subtask 3.2**: Persist filter preferences
  - Save filters to workspace state
  - Restore on panel reopen

---

### **Task 4**: Real-Time Data Binding

Connect panel to validation results.

- [ ] **Subtask 4.1**: Subscribe to validation results
  - Listen to DebouncedValidator output
  - Aggregate results across all open files
  - Update panel reactively

- [ ] **Subtask 4.2**: Performance optimization
  - Virtualized list for large issue counts (100+ issues)
  - Debounce panel updates (batch every 100ms)
  - Don't re-render unchanged issues

---

### **Task 5**: Tests

- [ ] **Subtask 5.1**: Unit tests for DiagnosticsPanel
  - Renders errors, warnings, info correctly
  - Click item → navigation called with correct position
  - Filter hides matching items
  - Search filters by message

- [ ] **Subtask 5.2**: Integration test
  - Open file with errors → panel shows issues
  - Click issue → editor jumps to location
  - Fix issue → panel updates
