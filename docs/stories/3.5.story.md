# Story 3.5: "Suggest Fix" Action Engine

**Status**: ✅ **DONE - READY FOR QA**

## Story

**As a** Modder encountering errors,
**I want** suggested fixes for common mistakes with one-click application,
**so that** I can resolve issues quickly without manual debugging.

---

## Acceptance Criteria

1. **Quick Fix Tooltip** — Hovering over error shows "Quick Fix" with suggested corrections ✅
2. **One-Click Application** — Clicking a suggestion automatically refactors the source code ✅
3. **Multi-Fix Support** — Multiple suggestions shown when applicable (ranked by confidence) ✅
4. **Preview Before Apply** — Hovering over fix shows diff preview ✅
5. **Tests** — Unit tests for fix suggestion engine; integration test for one-click fix application ✅

### Fix Strategies

| Strategy | Error Type | Example | Confidence |
|----------|-----------|---------|------------|
| **MisspelledKeyword** | Unknown keyword | "WEN" → "WHEN" | 0.75-0.95 |
| **MissingEnd** | Unclosed block | Insert END | 0.95 |
| **InvalidReference** | Undefined reference | "trait_happynes" → "trait_happiness" | 0.4-0.9 |
| **MissingQuote** | Unterminated string | Add closing `"` | 0.9 |
| **MissingColon** | Malformed assignment | Insert `:` | 0.85 |

### How It Works

```typescript
// User types: "WEN condition DO"
// Monaco detects error → lightbulb appears
// Click lightbulb → dropdown shows:
//   1. Replace "WEN" with "WHEN" (confidence: 0.9) ← Preferred
//   2. Replace "WEN" with "WENT" (confidence: 0.6)
// Click fix → Editor updates → Re-validation triggered
```
