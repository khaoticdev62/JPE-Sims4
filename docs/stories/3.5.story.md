# Story 3.5: "Suggest Fix" Action Engine

## Story

**As a** Modder encountering errors,
**I want** suggested fixes for common mistakes with one-click application,
**so that** I can resolve issues quickly without manual debugging.

---

## Acceptance Criteria

1. **Quick Fix Tooltip** — Hovering over error shows "Quick Fix" with suggested corrections
2. **One-Click Application** — Clicking a suggestion automatically refactors the source code
3. **Multi-Fix Support** — Multiple suggestions shown when applicable (ranked by confidence)
4. **Preview Before Apply** — Hovering over fix shows diff preview
5. **Tests** — Unit tests for fix suggestion engine; integration test for one-click fix application

---

## Tasks / Subtasks

### **Task 1**: Fix Suggestion Engine

Create the engine that generates fix suggestions for common errors.

- [ ] **Subtask 1.1**: Create `FixSuggestionEngine` class
  - Accept error type and context
  - Return ranked list of suggested fixes
  - Each fix: description, confidence score, diff to apply

- [ ] **Subtask 1.2**: Fix strategies for common errors
  - **Misspelled keyword**: "WEN" → suggest "WHEN" (edit distance matching)
  - **Missing keyword**: condition without WHEN → suggest adding WHEN
  - **Unclosed block**: missing END → suggest inserting END
  - **Invalid reference**: undefined trait → suggest similar names from registry
  - **Syntax error**: malformed string → suggest proper quoting

- [ ] **Subtask 1.3**: Confidence ranking
  - Score suggestions by likelihood
  - Show highest confidence first
  - Cap at 3 suggestions per error

---

### **Task 2**: Monaco Quick Fix Integration

Wire suggestions into Monaco's lightbulb/quick fix UI.

- [ ] **Subtask 2.1**: Register code action provider
  - Show lightbulb icon next to fixable errors
  - Click lightbulb → dropdown of suggestions
  - Each suggestion: description + "Apply" button

- [ ] **Subtask 2.2**: Diff preview
  - Hover over suggestion → show inline diff
  - Green for additions, red for deletions
  - Preview updates as user hovers different suggestions

---

### **Task 3**: Fix Application

Apply the selected fix to the source code.

- [ ] **Subtask 3.1**: Create `FixApplier` service
  - Accept fix diff (range + replacement text)
  - Apply to editor document
  - Record in undo history as single action
  - Trigger re-validation after fix

- [ ] **Subtask 3.2**: Undo support
  - Each fix applied as undoable transaction
  - "Undo Fix" available immediately after application
  - Toast notification: "Fix applied. Ctrl+Z to undo"

- [ ] **Subtask 3.3**: Multi-fix application
  - "Fix All" button for same error type across file
  - Preview all changes before applying
  - Confirm dialog for bulk fixes

---

### **Task 4**: Tests

- [ ] **Subtask 4.1**: Unit tests for FixSuggestionEngine
  - Misspelled keyword → correct suggestion
  - Missing block end → END insertion suggested
  - Invalid reference → similar names suggested
  - No fix available → empty result

- [ ] **Subtask 4.2**: Unit tests for FixApplier
  - Apply fix → document updated correctly
  - Fix recorded in undo stack
  - Re-validation triggered

- [ ] **Subtask 4.3**: Integration test
  - Type error in editor → lightbulb appears
  - Click lightbulb → suggestions shown
  - Click suggestion → fix applied, error resolved

## Dev Notes

### Fix Suggestion Pattern

Each fix strategy follows this pattern:
```typescript
interface FixStrategy {
  match(error: Diagnostic): boolean;
  suggest(error: Diagnostic, context: FixContext): FixSuggestion[];
}

interface FixSuggestion {
  description: string;
  confidence: number; // 0-1
  diff: TextDiff; // range + replacement
}
```

### Common Fix Catalog

| Error Type | Fix Strategy |
|------------|-------------|
| Unknown keyword | Edit-distance matching to keywords |
| Missing block end | Insert missing END/keywords |
| Unclosed string | Add closing quote |
| Invalid reference | Suggest similar from registry |
| Wrong operator | Suggest correct logical operator |
