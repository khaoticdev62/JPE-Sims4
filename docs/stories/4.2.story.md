# Story 4.2: .package File Reader & Asset List

## Story

**As a** Modder working with binary Sims 4 packages,
**I want** to browse the contents of .package files and open individual resources,
**so that** I can extract and edit tuning and strings without manual binary parsing.

---

## Acceptance Criteria

1. **Virtual File Tree** — Opening a .package file shows virtual directory structure with XML and STBL resources
2. **Resource Listing** — Display resource type, group, and instance ID for each entry
3. **Individual Resource Opening** — Select resources to open in editor tabs
4. **Non-Blocking Reads** — IDE doesn't lock .package file; other processes can access it simultaneously
5. **Tests** — Unit tests for package reader; integration test with real .package files

---

## Tasks / Subtasks

- [ ] **Subtask 1.1**: Create `PackageFileReader` class

## Dev Notes

### Sims 4 .package Format

Binary format structure:
- Header: magic, version, index offset, resource count
- Index: array of resource entries (type, group, instance, offset, size)
- Data: raw resource bytes at offsets

Resource type IDs are 32-bit hashes of type names.
