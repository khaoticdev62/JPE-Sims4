# Story 4.3: External Reference & "Mod Folder" Indexing

## Story

**As a** Modder with an existing mod collection,
**I want** the editor to recognize IDs and names from my installed mods,
**so that** I avoid reference errors when my mods depend on other installed content.

---

## Acceptance Criteria

1. **Background Indexing** — Sims 4 Mods directory scanned for tuning IDs and names on workspace init
2. **External Symbol Table** — Indexed IDs available for semantic validation (no false positives for external refs)
3. **Incremental Updates** — Index updated when mods folder changes
4. **External Reference Labeling** — References to external mods labeled as "external" in diagnostics
5. **Tests** — Unit tests for indexer; integration test with simulated mods folder

---

## Dev Notes

### Indexing Strategy

1. Full scan on workspace open (or first open)
2. Cache index to disk (JSON)
3. File watcher for incremental updates
4. Index structure:
   ```json
   {
     "symbols": {
       "trait:0x00000001": { "name": "trait_example", "source": "mod_x.package" },
       "buff:0x00000002": { "name": "buff_example", "source": "mod_y.xml" }
     },
     "lastScan": "2026-04-06T00:00:00Z",
     "fileHashes": { "mod_x.package": "sha256..." }
   }
   ```
