# Story 4.4: .ts4script Metadata & Python Integration

## Story

**As a** Modder bundling Python scripts with JPE-compiled mods,
**I want** to include .ts4script and .py files in my project with syntax highlighting,
**so that** I can manage complete mod packages from one workspace.

---

## Acceptance Criteria

1. **Python File Support** — .ts4script and .py files openable in editor with Python syntax highlighting
2. **Build Inclusion** — Python files included in final distributable .package or .zip on build
3. **Metadata Extraction** — Script metadata (name, author, version) displayed in file properties
4. **Basic Syntax Checking** — Python syntax errors flagged in editor
5. **Tests** — Unit tests for Python syntax checker; integration test for build inclusion

## Dev Notes

### .ts4script Files

.ts4script files are Sims 4 Python script files. They use standard Python 3 syntax and are loaded by the Sims 4 game engine at runtime. They may contain:
- Interaction scripts
- Custom tuning generators
- Game logic extensions

### Python Parsing Options

1. **Web-based**: Use a JS Python parser (e.g., `python-parser`) for client-side syntax checking
2. **IPC-based**: Spawn Python process via python-shell for validation
3. **Regex-based**: Basic syntax checking with regex (limited but fast)

Recommended: Option 1 for speed, fallback to Option 2 for accuracy.
