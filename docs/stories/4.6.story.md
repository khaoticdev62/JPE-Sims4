# Story 4.6: Custom Content (CC) Resource Support

## Story

**As a** Modder managing non-tuning assets in .package files,
**I want** to browse and preview textures, meshes, and other binary resources,
**so that** I can organize my complete mod packages visually alongside tuning files.

---

## Acceptance Criteria

1. **Resource Browser** — Non-tuning resources (PNG, DDS, LRLE) listed with Type, Group, Instance IDs
2. **Image Preview** — Selecting PNG/DDS resources displays visual preview in editor pane
3. **Resource Metadata** — Full metadata shown: type hash, group ID, instance ID, file offset, size
4. **Export Capability** — Resources can be exported as standalone files
5. **Tests** — Unit tests for resource extractor; integration test with image preview

---

## Tasks / Subtasks

Extend package reader to handle binary assets.

- [ ] **Subtask 1.1**: Create `CCResourceExtractor` class

  - Decode common formats: PNG, DDS, LRLE

- [ ] **Subtask 1.2**: Resource classification
  - Categorize by type: Textures, Meshes, Materials, Other

  - Generate thumbnail for image resources

Create the CC resource browsing interface.

- [ ] **Subtask 2.1**: Create `ResourceBrowser` component

  - Filter by resource type

- [ ] **Subtask 2.2**: Resource detail panel

### **Task 3**: Image Preview

Render image resources inline.

- [ ] **Subtask 3.1**: Create `ImageResourcePreview` component
  - Decode PNG/DDS binary to image
  - Display in preview panel with zoom controls
  - Show dimensions (width x height)
  - Alpha channel visualization for transparent images

- [ ] **Subtask 3.2**: DDS format support
  - Handle DDS mipmaps (show base level)
  - Support common DDS formats: DXT1, DXT5, BC7

## Dev Notes

### Supported Resource Types

| Type | Extension | Description |
|------|-----------|-------------|
| PNG | .png | Standard PNG images |
| DDS | .dds | DirectX texture format (DXT1, DXT5, BC7) |
| LRLE | .lrle | Compressed resource (needs decompression) |
| RLE2 | .rle2 | Sims 4 compressed format |

### DDS Decoding

For DDS preview, use a JS DDS decoder library or implement basic DXT1/DXT5 decompression. Alternative: convert DDS to PNG server-side via Python PIL.
