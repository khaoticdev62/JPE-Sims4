# Story 5.1: Interactive "My First Mod" Tutorial

## Story

**As a** New Modder launching JPE Studio for the first time,
**I want** a step-by-step guided tutorial that walks me through creating and compiling my first mod,
**so that** I can learn the workflow hands-on without leaving the application.

---

## Acceptance Criteria

1. **First-Launch Detection** — Tutorial auto-triggers on first app launch (skippable)
2. **Anchored Tooltips** — Step-by-step tooltips point to Sidebar, Editor, and Compile buttons
3. **Guided Creation** — User creates a simple "Hello World" JPE script following tutorial steps
4. **Completion Gate** — Tutorial completes only after successful JPE-to-XML compilation
5. **Re-accessible** — Tutorial available from Help menu after initial run
6. **Tests** — Unit tests for tutorial state machine; E2E test for full tutorial flow

---

## Tasks / Subtasks

### **Task 1**: Tutorial Engine

Create the tutorial state management and step progression system.

- [ ] **Subtask 1.1**: Create `TutorialEngine` service
  - Manage tutorial steps (ordered list with conditions)
  - Track current step, completion state
  - Support conditional steps (skip if user already knows)
  - Persist progress (resume where left off)

- [ ] **Subtask 1.2**: First-launch detection
  - Check localStorage for first-run flag
  - Auto-trigger tutorial if first launch
  - Allow skip with "Don't show again" option

---

### **Task 2**: Anchored Tooltip UI

Create tooltips that point to specific UI elements.

- [ ] **Subtask 2.1**: Create `AnchoredTooltip` component
  - Position tooltip next to target element (using refs)
  - Arrow pointing to target
  - Highlight target element (subtle glow/border)
  - Dim rest of UI (optional spotlight mode)

- [ ] **Subtask 2.2**: Navigation controls
  - "Next" / "Back" buttons
  - Step counter (e.g., "Step 3 of 8")
  - "Skip Tutorial" link

---

### **Task 3**: "My First Mod" Tutorial Content

Create the tutorial steps for the guided mod creation.

- [ ] **Subtask 3.1**: Tutorial steps definition
  1. Welcome: "Let's create your first mod!"
  2. Sidebar: "This is your project tree. Click 'New File'"
  3. Editor: "Type your first JPE line: WHEN sim_eats_food DO"
  4. Preview: "See the XML being generated on the right"
  5. Compile: "Click Build to create your mod file"
  6. Success: "Congratulations! Your first mod is ready"

- [ ] **Subtask 3.2**: Interactive validation
  - Each step checks if user completed the action
  - "Next" button disabled until action done
  - Hint text if user is stuck

---

### **Task 4**: Help Menu Integration

- [ ] **Subtask 4.1**: Add tutorial to Help menu
  - "Run Tutorial Again" menu item
  - Link to additional resources

- [ ] **Subtask 4.2**: Tutorial completion certificate
  - Show "Tutorial Complete" modal with next steps
  - Links to documentation, community, etc.

---

### **Task 5**: Tests

- [ ] **Subtask 5.1**: Unit tests for TutorialEngine
  - Steps progress in order
  - Conditional steps work correctly
  - Progress persisted across sessions
  - Skip stops tutorial

- [ ] **Subtask 5.2**: E2E test
  - Launch app first time → tutorial appears
  - Complete all steps → compilation succeeds
  - Tutorial marks as complete

## Dev Notes

### Tutorial Step Schema

```typescript
interface TutorialStep {
  id: string;
  title: string;
  content: string;
  anchorElement: string; // CSS selector or component ref
  validation?: () => boolean; // Check if step action completed
  hints?: string[]; // Help text if user is stuck
  skipAllowed?: boolean; // Can this step be skipped?
}
```
