# Story 5.2: In-App Documentation & API Lookup

## Story

**As a** Modder,
**I want** documentation for JPE keywords and Sims 4 elements available directly in the workspace,
**so that** I don't have to search online while coding.

---

## Acceptance Criteria

1. **Hover Documentation** — Hovering over JPE keywords or Sims 4 XML elements shows purpose and examples
2. **Searchable Help Center** — Dedicated sidebar with searchable index of complete JPE guide
3. **Context-Aware Suggestions** — Documentation relevant to current cursor context
4. **Offline-First** — All documentation available without internet connection
5. **Tests** — Unit tests for doc provider; integration test for hover display

---

## Tasks / Subtasks

### **Task 1**: Documentation Content System

Create the documentation data store and retrieval system.

- [ ] **Subtask 1.1**: Create `DocumentationStore`
  - Bundle JPE reference docs as JSON/Markdown
  - Index by keyword, category, and full-text search
  - Support cross-references between entries

- [ ] **Subtask 1.2**: Sims 4 API reference
  - Include Sims 4 tuning element reference
  - Common test types (`<V>`) and list types (`<L>`)
  - Attribute descriptions and valid values

---

### **Task 2**: Hover Documentation in Monaco

Wire docs into Monaco hover provider.

- [ ] **Subtask 2.1**: Create `DocHoverProvider`
  - Register Monaco hover provider for JPE language
  - On hover over keyword → show doc entry
  - Include description, syntax, examples
  - Link to full documentation entry

- [ ] **Subtask 2.2**: Sims 4 element hover
  - Hover over XML element names → show tuning docs
  - Show attribute documentation
  - Link to Sims 4 tuning reference

---

### **Task 3**: Help Center Sidebar

Create the searchable documentation panel.

- [ ] **Subtask 3.1**: Create `HelpCenter` component
  - Searchable index with full-text search
  - Category navigation (JPE Keywords, Sims 4 tuning, Tutorials)
  - Markdown rendering for doc content
  - Bookmark/favorite entries

- [ ] **Subtask 3.2**: Search functionality
  - Fuzzy search across titles and content
  - Filter by category
  - Recent entries history

---

### **Task 4**: Tests

- [ ] **Subtask 4.1**: Unit tests for DocumentationStore
  - Search returns relevant results
  - Cross-references resolve correctly
  - All bundled docs load successfully

- [ ] **Subtask 4.2**: Integration test
  - Hover over JPE keyword → doc shown
  - Search in Help Center → results displayed
  - Click result → full doc entry shown
