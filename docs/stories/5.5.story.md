# Story 5.5: High-Contrast & Custom Theme Support

## Story

**As a** User with visual sensitivities,
**I want** to select high-contrast and custom themes,
**so that** I can read the interface comfortably with colors that work for my eyes.

---

## Acceptance Criteria

1. **High-Contrast Theme** — Theme meets WCAG AAA contrast ratios for all text/UI elements
2. **Syntax Highlighting Adaptation** — Editor colors shift to high-visibility in high-contrast mode
3. **Theme Persistence** — Selected theme saved and restored across sessions
4. **Theme Preview** — Real-time preview before applying
5. **Tests** — Contrast ratio audit tests; theme switching integration tests

---

## Tasks / Subtasks

### **Task 1**: High-Contrast Theme Definition

Create the high-contrast theme token set.

- [ ] **Subtask 1.1**: Define high-contrast color tokens
  - Background: #000000 (pure black)
  - Foreground: #FFFFFF (pure white)
  - Accent: #00FFFF (cyan, high contrast)
  - Error: #FF4444 (bright red)
  - Warning: #FFAA00 (bright amber)
  - Success: #00FF00 (bright green)

- [ ] **Subtask 1.2**: WCAG AAA verification
  - All text/background combinations ≥ 7:1 contrast
  - UI elements ≥ 3:1 contrast
  - Document any exceptions (decorative elements)

---

### **Task 2**: Theme System Enhancement

Extend the theme system for custom themes.

- [ ] **Subtask 2.1**: Theme selection UI
  - Dropdown in settings with available themes
  - Preview thumbnail for each theme
  - "Apply" and "Preview" buttons

- [ ] **Subtask 2.2**: Theme provider
  - React context providing theme tokens
  - Dynamic CSS variable updates
  - Smooth transition between themes (300ms)

---

### **Task 3**: Editor Syntax Theme Adaptation

Adapt Monaco syntax highlighting per theme.

- [ ] **Subtask 3.1**: Monaco theme definitions
  - Define syntax colors for each theme
  - High-contrast: bright, distinct colors per token type
  - Map Spectral theme colors to Monaco tokens

- [ ] **Subtask 3.2**: Theme switching for editor
  - Editor updates syntax colors on theme change
  - No flicker during transition

---

### **Task 4**: Theme Preview

- [ ] **Subtask 4.1**: Preview mode
  - "Preview" button applies theme temporarily
  - 10-second countdown with "Keep" / "Revert"
  - Auto-revert if no selection

- [ ] **Subtask 4.2**: Side-by-side preview
  - Show current theme and new theme side by side
  - Sample code snippet displayed in both

---

### **Task 5**: Tests

- [ ] **Subtask 5.1**: Contrast ratio audit
  - Automated contrast check for all text/background pairs
  - All ≥ 7:1 for high-contrast theme
  - Report violations

- [ ] **Subtask 5.2**: Integration tests

  - Editor syntax colors update

## Dev Notes

### WCAG Contrast Requirements

| Level | Normal Text | Large Text |
|-------|------------|------------|
| AA    | 4.5:1      | 3:1        |
| AAA   | 7:1        | 4.5:1      |

High-contrast theme targets AAA.

### Theme Token Structure

```typescript
interface ThemeTokens {
  colors: {
    background: string;
    surface: string;
    primary: string;
    text: string;
    textSecondary: string;
    error: string;
    warning: string;
    success: string;
  };
  syntax: {
    keyword: string;
    string: string;
    comment: string;
    number: string;
    // ... Monaco token types
  };
}
```
