# Story 5.6: Interactive "Just Plain Manual" (JPM)

## Story

**As a** New or Advanced Modder,
**I want** a comprehensive, interactive manual that explains JPE Studio through examples and playgrounds,
**so that** I can learn both basic workflows and advanced industrial functions at my own pace.

---

## Acceptance Criteria

1. **Getting Started Guide** — Modular syntax explained through interactive examples
2. **Interactive Playgrounds** — Code samples editable and runnable within the manual
3. **Pro Utilities Section** — Advanced topics: stream writer, manifest patching, collision cleanup
4. **Context-Aware Highlighting** — Manual highlights relevant sections based on current workspace view
5. **Tests** — Unit tests for manual content structure; integration test for playground interactivity

---

## Tasks / Subtasks

### **Task 1**: Manual Content System

Create the structured manual content and navigation.

- [ ] **Subtask 1.1**: Create `ManualContent` data structure
  - Organize content into sections and subsections
  - Each section: title, content (markdown), code examples
  - Support embedded interactive code blocks

- [ ] **Subtask 1.2**: Manual content definition
  - **Getting Started**: Installation, first launch, UI overview
  - **JPE Basics**: WHEN/DO/ONLY_IF syntax, conditions, actions
  - **JPE Advanced**: Nested conditions, variables, expressions
  - **Pro Utilities**: Stream writer, manifest patching, collision cleanup
  - **Reference**: Complete keyword and API reference

---

### **Task 2**: Interactive Playgrounds

Embed editable, runnable code examples within the manual.

- [ ] **Subtask 2.1**: Create `InteractivePlayground` component
  - Embedded mini Monaco editor with code example
  - "Run" button compiles and shows result
  - Side-by-side: JPE input → XML output
  - "Reset" button restores original example

- [ ] **Subtask 2.2**: Sandbox execution
  - Playgrounds run in isolated context
  - No impact on user's actual project
  - Results displayed inline

---

### **Task 3**: Context-Aware Navigation

- [ ] **Subtask 3.1**: Create `ContextAwareManual` component
  - Detect current workspace view (editor, browser, etc.)
  - Highlight relevant manual sections
  - "Read more about this" suggestions

- [ ] **Subtask 3.2**: Table of contents
  - Collapsible sidebar navigation
  - Search within manual
  - Bookmark sections

---

### **Task 4**: Manual UI Integration

- [ ] **Subtask 4.1**: Help Center integration

  - Full-screen mode for reading

### **Task 5**: Tests
