# Story 6.2: "Prompt-to-JPE" Automated Mod Creation

## Story

**As a** Modder,
**I want** to generate mod skeletons from natural language prompts,
**so that** I can start building complex logic faster without writing boilerplate from scratch.

---

## Acceptance Criteria

1. **Natural Language Input** — User enters plain English description of desired mod behavior
2. **JPE Code Generation** — AI generates valid JPE code structure matching the description
3. **Auto-Insertion** — Generated code inserted into editor with explanatory comments
4. **Validation** — Generated JPE passes syntax validation before insertion
5. **Tests** — Unit tests for prompt formatter; integration test with mock AI generation

---

## Tasks / Subtasks

### **Task 1**: Prompt Engineering

Design the prompt templates for JPE generation.

- [ ] **Subtask 1.1**: Create `PromptTemplateEngine`
  - Build system prompts for JPE generation
  - Include JPE syntax reference in prompts
  - Add examples of common patterns
  - Format user description into complete prompt

- [ ] **Subtask 1.2**: Prompt variations
  - Simple mode: basic interaction/buff/trait
  - Complex mode: nested conditions, multiple actions
  - Template selection based on user input analysis

---

### **Task 2**: Code Generation Service

Create the generation pipeline.

- [ ] **Subtask 2.1**: Create `JPEGeneratorService`
  - Send prompt to selected AI provider
  - Parse AI response to extract JPE code
  - Validate generated code with syntax checker
  - Return validated JPE or error

- [ ] **Subtask 2.2**: Response parsing
  - Extract JPE code from AI response (handle markdown blocks)
  - Clean up any AI commentary
  - Validate syntax before returning

---

### **Task 3**: Editor Integration

- [ ] **Subtask 3.1**: Create `PromptToJPE` dialog
  - Text input for natural language prompt
  - Provider selection dropdown
  - "Generate" button with loading state
  - Cancel option during generation

- [ ] **Subtask 3.2**: Code insertion
  - Generated code inserted at cursor position
  - Each section preceded by comment: `# AI-generated: <description>`
  - "Undo Generation" available immediately
  - Syntax errors highlighted after insertion

---

### **Task 4**: Tests

- [ ] **Subtask 4.1**: Unit tests for PromptTemplateEngine
  - Simple prompt formatted correctly

  - Examples included in prompt

- [ ] **Subtask 4.2**: Unit tests for JPEGeneratorService

## Dev Notes

### Prompt Template Example

```
You are a JPE code generator. Given a description of Sims 4 mod behavior,
generate valid JPE code.

JPE Syntax Reference:
- WHEN <condition> DO ... END
- ONLY_IF <condition> ... END
- sim_has_trait("trait_name")
- interaction_apply_buff("buff_name")

Rules:
1. Only output valid JPE code
2. Use descriptive names
3. Add comments for complex logic
4. Do not explain outside the code block

Description: {userDescription}

Generate JPE code:
```
