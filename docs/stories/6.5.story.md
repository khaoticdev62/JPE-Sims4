# Story 6.5: Predictive Scripting & Context-Aware Autocomplete

## Story

**As a** Modder,
**I want** intelligent suggestions for Sims 4 IDs and JPE patterns as I type,
**so that** I don't have to memorize thousands of game hashes and can code fluidly.

---

## Acceptance Criteria

1. **Context-Aware Suggestions** — Suggestions relevant to current cursor position and block context
2. **Sims 4 ID Completion** — Tuning IDs and names suggested as user types references
3. **<300ms Response Time** — Suggestions appear within 300ms to maintain fluid typing
4. **Pattern Suggestions** — Common JPE patterns suggested (e.g., "WHEN sim_" → complete common conditions)
5. **Tests** — Unit tests for suggestion engine; performance test for response time

---

## Tasks / Subtasks

### **Task 1**: Context Analyzer

Analyze current editing context for relevant suggestions.

- [ ] **Subtask 1.1**: Create `ContextAnalyzer` service
  - Analyze current line and surrounding context
  - Determine expected token type (keyword, reference, value)
  - Identify current block scope (inside WHEN, inside DO, etc.)

- [ ] **Subtask 1.2**: Context classification
  - **Keyword context**: Expecting JPE keywords
  - **Reference context**: Expecting trait/buff/interaction names
  - **Value context**: Expecting numbers, strings, operators
  - **Condition context**: Expecting condition functions

---

### **Task 2**: Suggestion Engine

Generate and rank suggestions based on context.

- [ ] **Subtask 2.1**: Create `PredictiveSuggestionEngine`
  - Given context, return ranked suggestions
  - Sources: JPE keywords, project symbols, Sims 4 registry, recent completions
  - Rank by relevance to current context and usage frequency

- [ ] **Subtask 2.2**: Suggestion types
  - **Keywords**: WHEN, DO, ONLY_IF, etc.
  - **References**: Known trait/buff/interaction names
  - **Patterns**: Common condition patterns (sim_has_*, interaction_*)
  - **Recent**: Recently used identifiers

- [ ] **Subtask 2.3**: Fuzzy matching
  - User types partial → match closest names
  - Edit distance scoring for ranking
  - Cap at 10 suggestions

---

### **Task 3**: Monaco Integration

Wire suggestions into Monaco autocomplete.

- [ ] **Subtask 3.1**: Enhanced completion provider
  - Register completion provider with context analysis
  - Suggestions shown as user types
  - Icons per suggestion type (keyword, reference, pattern)
  - Detail popup shows description for selected suggestion

- [ ] **Subtask 3.2**: Performance optimization
  - Pre-load common suggestions
  - Cache suggestion results for same context
  - Background refresh of Sims 4 registry

---

### **Task 4**: Tests

- [ ] **Subtask 4.1**: Unit tests for ContextAnalyzer
  - Correctly identifies keyword context
  - Correctly identifies reference context
  - Handles incomplete lines gracefully

- [ ] **Subtask 4.2**: Unit tests for PredictiveSuggestionEngine
  - Relevant suggestions returned for context
  - Ranking orders by relevance
  - Fuzzy matching works for typos

- [ ] **Subtask 4.3**: Performance test
  - Suggestions appear within 300ms of typing
  - No UI stutter during suggestion loading
  - Cache hits under 50ms

## Dev Notes

### Suggestion Ranking Formula

```
score = (contextRelevance * 0.4) + (usageFrequency * 0.3) + (fuzzyMatchScore * 0.3)
```
