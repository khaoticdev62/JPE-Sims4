# Story 7.1: Mods Folder Cleanup & Organizer Utility

## Story

**As a** Modder with a cluttered Sims 4 Mods folder,
**I want** a professional tool to scan for duplicates, broken links, and orphaned files,
**so that** I can maintain a clean, high-performance mod environment.

---

## Acceptance Criteria

1. **Duplicate Detection** — Identifies duplicate files using MD5 hashing and Instance ID comparison
2. **Categorized Report** — Results grouped as "Duplicates," "Broken Links," "Orphaned Files"
3. **Safe Move Action** — Identified files can be relocated to a backup directory
4. **Dry Run Mode** — Preview changes before executing
5. **Tests** — Unit tests for duplicate detector; integration test with simulated mods folder

---

## Tasks / Subtasks

### **Task 1**: Duplicate Detector

Create the scanning engine for duplicate detection.

- [ ] **Subtask 1.1**: Create `DuplicateDetector` service
  - Scan Mods directory for all mod files
  - Compute MD5 hash for each file
  - Group files by matching hash
  - Also compare Instance IDs within .package files

- [ ] **Subtask 1.2**: Duplicate classification
  - **Exact duplicate**: Same hash, different name/location
  - **Partial duplicate**: Overlapping content (shared resources)
  - **Version duplicate**: Same mod, different versions

---

### **Task 2**: Broken Link & Orphan Detector

Find files with broken references.

- [ ] **Subtask 2.1**: Create `LinkValidator` service
  - Parse mod files for cross-references
  - Check all referenced files exist
  - Report broken links (reference to missing file)
  - Report orphaned files (not referenced by anything)

- [ ] **Subtask 2.2**: Dependency graph
  - Build graph of mod dependencies
  - Identify isolated clusters (orphaned groups)
  - Visualize dependency chains

---

### **Task 3**: Cleanup UI

Create the cleanup tool interface.

- [ ] **Subtask 3.1**: Create `ModsCleanupTool` component
  - "Scan Mods Folder" button
  - Progress bar during scan
  - Results grouped by category (Duplicates, Broken, Orphaned)
  - Selectable items with checkboxes

- [ ] **Subtask 3.2**: Action buttons
  - "Safe Move" → selected files to backup folder
  - "Delete" → permanently remove (with confirmation)
  - "Dry Run" → preview without changes
  - Undo last action

---

### **Task 4**: Tests

- [ ] **Subtask 4.1**: Unit tests for DuplicateDetector
  - Identifies exact duplicates correctly
  - Handles large files efficiently
  - No false positives

- [ ] **Subtask 4.2**: Unit tests for LinkValidator
  - Broken links detected
  - Orphaned files identified
  - Valid links not flagged

- [ ] **Subtask 4.3**: Integration test
  - Test Mods folder with known issues
  - Scan → correct issues reported
  - Safe Move → files relocated, originals removed

## Dev Notes

### MD5 Hashing Strategy

For large files, use streaming hash (don't load entire file into memory):
```typescript
const hash = crypto.createHash('md5');
const stream = fs.createReadStream(filePath);
stream.pipe(hash);
```
