# Story 7.3: Intelligent Mod Compatibility & Update System

## Story

**As a** Modder with a local Sims 4 installation,
**I want** a dashboard that tracks mod compatibility against community data and local crash reports,
**so that** I can quickly identify which mods need updates after a game patch.

---

## Acceptance Criteria

1. **Game Version Detection** — System reads local `GameVersion.txt` to detect current game version
2. **Community Data Cross-Reference** — Installed mods checked against Scarlet's Realm "Mod List" (Broken/Updated/Fine)
3. **Better Exceptions Parsing** — Local BE HTML reports parsed for specific failing tunings
4. **Prioritized Action List** — "Action Required" list with one-click update links where available
5. **Tests** — Unit tests for compatibility checker; integration test with simulated mod data

---

## Tasks / Subtasks

### **Task 1**: Game Version Detector

Detect the installed Sims 4 game version.

- [ ] **Subtask 1.1**: Create `GameVersionDetector`
  - Read `GameVersion.txt` from Sims 4 installation directory
  - Parse version string (e.g., "1.104.123.1020")
  - Cache version for future checks

- [ ] **Subtask 1.2**: Version comparison
  - Compare installed version against known patch versions
  - Detect if game was recently updated
  - Warn about potential mod incompatibilities

---

### **Task 2**: Community Data Integration

Fetch and parse community mod compatibility data.

- [ ] **Subtask 2.1**: Create `CommunityModTracker`
  - Fetch Scarlet's Realm "Mod List" data
  - Parse mod status: Broken, Updated, Fine
  - Match local mods against community list
  - Cache community data (refresh daily)

- [ ] **Subtask 2.2**: Matching algorithm
  - Match by mod name (fuzzy matching)
  - Match by file hash (exact matching)
  - Handle mod renames and re-uploads

---

### **Task 3**: Better Exceptions Parser

Parse local BE reports for crash analysis.

- [ ] **Subtask 3.1**: Create `BETuningParser`
  - Parse Better Exceptions HTML reports
  - Extract failing tuning IDs and mod names
  - Map tunings to specific installed mods

- [ ] **Subtask 3.2**: Crash attribution
  - Identify which mod is causing each crash
  - Group crashes by mod
  - Severity assessment (game-breaking vs cosmetic)

---

### **Task 4**: Compatibility Dashboard UI

- [ ] **Subtask 4.1**: Create `CompatibilityDashboard` component
  - Game version display
  - Mod compatibility summary (X broken, Y updated, Z fine)
  - "Action Required" list prioritized by severity
  - One-click update links for available updates

- [ ] **Subtask 4.2**: Status indicators
  - Green checkmark: Fine
  - Amber warning: Update available
  - Red X: Broken, needs attention
  - Gray: Unknown/not checked

---

### **Task 5**: Tests

- [ ] **Subtask 5.1**: Unit tests for GameVersionDetector
  - Correctly parses version file
  - Handles missing file gracefully
  - Version comparison works

- [ ] **Subtask 5.2**: Unit tests for CommunityModTracker
  - Community data fetched and parsed
  - Local mods matched correctly
  - Fuzzy matching handles name variations

- [ ] **Subtask 5.3**: Integration test
  - Scan local mods → compatibility dashboard populated
  - Broken mods highlighted
  - Update links functional
