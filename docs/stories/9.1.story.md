# Story 9.1: Automated Live-Bridge Deployment

## Story

**As a** Modder who wants real-time game engine feedback,
**I want** JPE Studio to automatically handle the Sims 4 engine link setup,
**so that** I get live diagnostics without manually installing script mods.

---

## Acceptance Criteria

1. **Passive Injection** — "Enable JPE-Live" toggle auto-injects `jpe_live_sync.ts4script` into Mods folder
2. **Version Handshake** — Bridge performs version check with game process
3. **Auto-Redeploy** — Script automatically redeployed if version mismatch detected
4. **Non-Destructive** — Existing Mods folder not modified beyond bridge script addition
5. **Tests** — Unit tests for bridge deployer; integration test with simulated game process

---

## Dev Notes

### Communication Channel

JPE Studio ↔ Sims 4 bridge options:
1. **Local socket**: Bridge script sends to localhost:port
2. **File-based**: Bridge writes to log file, JPE Studio tails
3. **Named pipe**: Cross-process IPC

Recommended: Local socket for real-time, file-based as fallback.

### Bridge Script Template

```python
# jpe_live_sync.ts4script

import threading

JPE_STUDIO_PORT = 19420

    """Send tuning event to JPE Studio"""

def on_tuning_execute(tuning_id, context):
    send_event("tuning_execute", {"id": tuning_id, "context": context})
```
