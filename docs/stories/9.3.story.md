# Story 9.3: Human-Readable Alert Translation

## Story

**As a** Modder debugging game crashes,
**I want** raw engine tracebacks translated into understandable JPE logic errors,
**so that** I can quickly identify which line of my script is failing and why.

---

## Acceptance Criteria

1. **Traceback Mapping** — Engine error mapped to specific JPE source file and line number
2. **Spectral Alert Card** — Human-readable explanation displayed as branded alert
3. **Remediation Suggestions** — Suggested fixes based on previous successful translations
4. **Severity Filtering** — Only 'Exception' or 'Critical' signatures trigger sensory alerts
5. **Tests** — Unit tests for error translator; integration test with simulated errors

---

## Tasks / Subtasks

### **Task 1**: Error Translator

Create the traceback-to-JPE translation engine.

- [ ] **Subtask 1.1**: Create `EngineErrorTranslator`
  - Accept raw Sims 4 exception/traceback
  - Parse stack trace to find tuning ID
  - Map tuning ID to JPE source file and line
  - Generate human-readable explanation

- [ ] **Subtask 1.2**: Error classification
  - **Exception**: Python exception in script mod
  - **Critical**: Tuning logic failure
  - **Warning**: Non-critical issue
  - Only Exception/Critical trigger full alert

---

### **Task 2**: Alert Card UI

Create the branded alert display.

- [ ] **Subtask 2.1**: Create `SpectralAlertCard` component
  - Branded alert with Spectral design (red/amber glow for errors)
  - Error title and human-readable explanation
  - Source file link (click to open at error line)
  - Severity badge (Exception/Critical/Warning)

- [ ] **Subtask 2.2**: Remediation suggestions
  - "Suggested Fix" section
  - Based on similar past errors
  - "Apply Fix" button (links to AI fix from Story 6.4)

---

### **Task 3**: Alert Pipeline

Wire error detection to alert display.

- [ ] **Subtask 3.1**: Error detection in event stream
  - Monitor TuningEventProcessor for error events
  - Filter by severity (only Exception/Critical)
  - Send to translator

- [ ] **Subtask 3.2**: Alert display
  - Show alert card in Live Log Viewer
  - Also show in DiagnosticsPanel
  - Sensory cues: red pulse, error sound (if sensory enabled)

---

### **Task 4**: Tests

- [ ] **Subtask 4.1**: Unit tests for EngineErrorTranslator
  - Traceback parsed to correct file/line
  - Human-readable explanation generated
  - Unknown error handled gracefully

- [ ] **Subtask 4.2**: Unit tests for SpectralAlertCard

## Dev Notes

### Traceback Format

Sims 4 tracebacks look like:
```
Exception in tuning: interaction:0x00000001
File "Scripts/tuning/interaction.py", line 42
  self.apply_buff(buff_id)
ValueError: buff_id 0x00000002 not found
```

Need to map `interaction:0x00000001` to JPE source file.
