# Story 9.4: Link Fail-Safe & Damped Pulse

## Story

**As a** Modder,
**I want** JPE Studio to gracefully handle lost game connections,
**so that** my IDE doesn't crash or hang if I close the game unexpectedly.

---

## Acceptance Criteria

1. **Damped Gray Null-Pulse** — Status indicator transitions to gray null-pulse on disconnect
2. **Buffer Cleanup** — All live telemetry buffers cleared to prevent memory leaks
3. **Clear Notification** — "Link Severed" notification shown without interrupting editor
4. **Auto-Reconnect** — Option to auto-reconnect when game restarts
5. **Tests** — Unit tests for disconnect handler; integration test for graceful teardown

---

## Tasks / Subtasks

### **Task 1**: Disconnect Detection

Detect when the game process or bridge connection is lost.

- [ ] **Subtask 1.1**: Create `ConnectionMonitor`
  - Monitor socket connection to bridge script
  - Detect disconnect (socket closed, timeout, game process ended)
  - Emit disconnect event with reason

- [ ] **Subtask 1.2**: Reconnect strategy
  - Auto-reconnect after delay (exponential backoff)
  - Max reconnect attempts before giving up
  - Manual reconnect button always available

---

### **Task 2**: Graceful Teardown

Clean up resources on disconnect.

- [ ] **Subtask 2.1**: Create `BridgeTeardownManager`
  - Clear ring buffer of pending events
  - Close socket connections
  - Stop event receiver server
  - Clear all pending alerts related to live bridge
  - Prevent memory leaks from orphaned references

- [ ] **Subtask 2.2**: State transition
  - Update bridge status: Connected → Disconnecting → Disconnected
  - Trigger "Damped Gray Null-Pulse" visual status
  - Preserve editor state (don't lose work)

---

### **Task 3**: Notification & UI

- [ ] **Subtask 3.1**: "Link Severed" notification
  - Non-blocking toast notification
  - Message: "Game connection lost. Click to reconnect."
  - "Reconnect" button in notification
  - Auto-dismiss after 10 seconds

- [ ] **Subtask 3.2**: Status indicator
  - Connected: Teal pulse
  - Disconnecting: Amber fade
  - Disconnected: Gray null-pulse (no animation)
  - Hover tooltip shows disconnect reason

---

### **Task 4**: Tests

- [ ] **Subtask 4.1**: Unit tests for ConnectionMonitor
  - Disconnect detected when socket closes
  - Timeout detected after no heartbeat
  - Reconnect logic works

- [ ] **Subtask 4.2**: Unit tests for BridgeTeardownManager
  - All buffers cleared
  - No memory leaks after teardown
  - Pending events discarded safely

- [ ] **Subtask 4.3**: Integration test
  - Connected → close game → disconnected
  - Status shows gray null-pulse
  - Notification displayed
  - Reconnect works when game restarted

---

## Dev Notes

### Damped Null-Pulse Visual

Unlike the active teal pulse (bioluminescent heartbeat), the null-pulse is:
- Gray color (neutral)
- No animation (static)
- Lower opacity (damped)
- Indicates "waiting for connection"

### Reconnect Backoff

```
Attempt 1: 1 second
Attempt 2: 2 seconds
Attempt 3: 4 seconds
Attempt 4: 8 seconds
...
Attempt 10: Give up, show manual reconnect
```
