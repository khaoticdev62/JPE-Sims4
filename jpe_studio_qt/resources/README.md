# Qt Resources

This folder is reserved for **offline-bundled** Studio (Qt) resources (fonts/icons) used to match the `JPE assets folder/` templates without relying on network-hosted Google Fonts.

## Fonts

Place `.ttf` / `.otf` files under:

- `jpe_studio_qt/resources/fonts/`

The app will auto-load them on startup via `jpe_studio_qt/fonts.py`.

Recommended bundles for desktop parity:
- Inter (UI)
- JetBrains Mono (code)
- Material Symbols Outlined (icons)
